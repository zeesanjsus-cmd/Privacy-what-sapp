# Play Store release checklist

1. Create a unique Android application ID/package name.
2. Configure release signing and build an Android App Bundle (AAB).
3. Connect real backend services and production secrets outside the APK.
4. Prepare privacy policy, Data Safety information, app description, screenshots and app icon.
5. Test OTP, account creation/deletion, reports, blocking, notifications, media and calls.
6. Run internal/closed testing and resolve crashes before production.
7. Submit the signed AAB through Google Play Console and complete required declarations/review.
